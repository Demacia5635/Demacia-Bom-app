# Extension v2.1.1

**Unreleased.** Committed on `MASTER` (`f482e8d`, `24d5d60`), not pushed or built yet. Replaces [v2.0.0](../2.0.0/v2.0.0.md).

The website is already at 2.1.0 and the extension shares `package.json` with it, so the next extension version is 2.1.1. Set `package.json` to `2.1.1` before building the zip.

## Changes

- **Problem cells are easier to see.** Red (problem) cells have a stronger red tint and a thicker red underline. Frozen columns now show the tint too: before, their background hid it. The "N problems" button and the top-assembly warning are a deeper red instead of pink. (`f482e8d`)
- **A failed check of the Onshape page says why.** When the extension can't read the open Onshape document, the warning in `chrome://extensions` now includes Onshape's own reason, not just "Onshape API 403". A 403 (no access) or 404 (not found) is no longer retried 3 times, so there's one warning instead of four. The Demacia button still stays hidden on that page. (`24d5d60`)

## Known problem

- The cause of the 403 isn't fixed yet. This version only shows more about it.

## Not tested yet

- Neither change has been checked in the real extension panel in Onshape.
