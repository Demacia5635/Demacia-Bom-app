# Extension v2.3.0

**Unreleased.** Committed on `MASTER` (`806ae5d`, `11e0acd`), not pushed or built yet. Replaces [v2.2.0](../2.2.0/v2.2.0.md).

Set `package.json` to `2.3.0` before building the zip.

## Changes

- **Polycarbonate parts get a Parasolid, not an STL.** Polycarbonate (also "PC" and "Lexan") is cut from sheet on the CNC, so a new part made of it is ticked Parasolid by default. Before, it was treated as a printing plastic. Printing blends such as "PC-ABS" still get an STL. (`806ae5d`, `11e0acd`)
- **Changing a part's material re-ticks its files.** Printing plastics get STL, aluminum and polycarbonate get Parasolid, and Delrin gets neither. A material with no rule (e.g. steel) leaves the ticks as they were. You can still change the ticks afterwards. (`806ae5d`)
