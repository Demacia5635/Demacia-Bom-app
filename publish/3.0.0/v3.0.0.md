# Extension v3.0.0

**Built:** 2026-11-17 23:17 from `ec8e796` (commits `f482e8d`–`11e0acd`). Combines the earlier 2.2.0 and 2.3.0. Replaces [v2.0.0](../2.0.0/v2.0.0.md).

The 2.2.0 part was handed out once as a 2.2.0 zip (2026-11-17 22:52). That zip was deleted; use this one.

## Before handing it out

- **Redeploy the server on Render first** (server v3.0.0). Until then, Publish BOM saves everything except the part sizes, without any error.

## New

- **Show part sizes.** A **Show size** checkbox (next to "Hide standard assemblies") adds a read-only **Size** column after Name, e.g. `25 × 8 × 8 mm`. It shows each made part's bounding box from Onshape, longest side first, so you can tell spacers and shafts apart. Bought parts (standard, vendor or marked standard) and assemblies get no size. The browser remembers the checkbox. (`4e9f2bd`, `7cd6231`)
  - Saved sizes show at once. A size is read from Onshape only when there's none yet or the part's Part Studio changed since it was saved, only while the box is ticked, and at most 4 at a time.
  - **Publish BOM saves each made part's size** for the website (the work-order CNC jobs use it too), reading it from Onshape only when it's missing or out of date. It never blanks a size that's already saved.
  - A BOM copy that hasn't been refreshed can show an old size until you press Refresh BOM. Publish BOM checks it again anyway.
  - The box is aligned with the Part Studio's axes, so a part drawn at an angle shows bigger than it really is.

## Changes

- **Clicking the toolbar icon or the in-page "BOM" button again closes the panel.** Before, it only opened it. On Chrome before version 141 the panel is closed by switching it off for that tab; the next click opens it again. (`30b4530`)
- **Polycarbonate parts get a Parasolid, not an STL.** Polycarbonate (also "PC" and "Lexan") is cut from sheet on the CNC. Printing blends such as "PC-ABS" still get an STL. (`806ae5d`, `11e0acd`)
- **Changing a part's material re-ticks its files.** Printing plastics get STL, aluminum and polycarbonate get Parasolid, and Delrin gets neither. A material with no rule (e.g. steel) leaves the ticks as they were. You can still change them afterwards. (`806ae5d`)
- **Problem cells are easier to see.** Red (problem) cells have a stronger red tint and a thicker red underline. Frozen columns now show the tint too. The "N problems" button and the top-assembly warning are a deeper red instead of pink. (`f482e8d`)
- **A failed check of the Onshape page says why.** The warning in `chrome://extensions` now includes Onshape's own reason, not just "Onshape API 403". A 403 (no access) or 404 (not found) is no longer retried 3 times, so there's one warning instead of four. The Demacia button still stays hidden on that page. (`24d5d60`)
- **A column you show appears next to its neighbour,** not at the far right, even after you've dragged columns around. (`420e89f`, shared with the website)

## Known problems

- The cause of the 403 on some documents isn't fixed yet. This version only shows more about it.

## Not tested yet

- None of it has run in the real panel in Onshape. That includes the panel toggle in Chrome and Firefox (on Firefox, the in-page button may not be allowed to close the sidebar), whether Onshape's bounding-box request returns what's expected, the Show size checkbox in both themes, and the material rules (checked on sample names only).
