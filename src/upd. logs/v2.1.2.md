# Website v2.1.2

**Unreleased.** Merged into `MASTER`, not pushed yet. A small update (+0.0.1).

## Changes

- **Bought items in a work order have their own status:** Onshape Standard Content, parts marked standard, vendor parts and bought sub-assemblies choose between **Untracked**, **To buy** (orange) and **Finished** (green), instead of the manufacturing list. New work orders still start them at "Untracked". In older work orders, a bought item saved as "Finished Manufacturing" shows as Finished and any other manufacturing status as To buy; nothing is rewritten until you pick a status. Finished also hides it with "Hide finished parts". Their method stays "Purchased", and they don't count towards the progress bars and totals, which only count made parts. (`68aca0b`, `61c1e18`)
- **The Work Orders list's status line counts made parts only,** so it matches the progress bar (needs server 4.1.1).
