# Website v2.1.0

**Unreleased.** Committed on `MASTER` (`cd99eb5`), not pushed yet.

## New

- **Three views of a BOM.** A **View** switch above the table on a BOM page:
  - **Single-level** (the default, as before): sub-assemblies are rows, like parts.
  - **Structured:** open a sub-assembly with ▶ to see its own parts and sub-assemblies, like on the main BOMs table.
  - **Flattened:** the same tree with every sub-assembly already open, like the extension's BOM inside Onshape.

  Quantities are per parent, as in Onshape's structured BOM. Editing a part changes every row of that part, and edits are kept when you switch views. The browser remembers the view you chose. (`cd99eb5`)

## Tested

- Checked in a real browser by the user on 2026-11-16: all three views work.
