# Website v2.1.0

**Unreleased.** On branch `fix/web` (quality-of-life round), not on `MASTER` yet. A medium update (+0.1.0).

## New

- **Press `/` to jump to the search box** on the Parts, Standard Parts, BOMs and Work Orders pages; Esc clears it. **The BOMs page has a search box** (name or catalog number). (QW1, `fea957e`)
- **Search Parts also finds parts by material, engineer, description and vendor,** ignoring case and extra spaces, and highlights the matching text. (QW2, `fea957e`)
- **Share a part by link:** Part Portal has a **Copy link** button, and opening that link (`…/#/partSearch?part=<id>`) opens the part's card directly. While a part is open on any page, the address includes it, so you can copy the address too. The extension's "Open on the website" uses the same link. (QW5, `0cec75e`)
- **Copy a catalog number with one click:** a small copy icon appears next to catalog numbers on hover (part cards, BOM / work-order / sub-assembly headers, Part Portal, the work-order list), with a short "Copied" note. Inside the BOM and work-order tables it comes later. (QW6, `0cec75e`)
- **A save indicator next to the BOM and work-order tables:** "Saving…" while edits are being sent, "Saved ✓" for a few seconds after, and "Not saved" in red when a save fails (the red error box stays too). (QW12, `909f9ee`)
- **A warning before leaving with unsaved edits:** closing or reloading the tab, or clicking a sidebar link, while an edit is still being saved or has failed asks first. (QW13, `306ebf6`)
- **Pulsing grey placeholders while lists and tables load,** instead of "Loading…" text. (QW20, `aa3fd89`)
- **Totals in the header card,** in the middle next to the description and engineer: on a BOM page "N parts · total quantity Q", on a work order "N parts · Q pieces · F finished (P%)". (QW11, `2251607`)
- **A BOM page lists its work orders** (name, owner, date; click to open), and **a work order has an "Open BOM" link** back to its assembly. (QW4, `d1eec77`)
- **Messages appear as small notes in the bottom-right corner** (red for errors, grey for information) that close by themselves after a few seconds or on a click, instead of browser pop-ups you had to dismiss. (QW19, `b39f9c6`)
- **When you move around with the keyboard, the focused button or field gets a clear blue outline** (not when clicking with the mouse), and in light mode the faintest grey text (like "NO IMAGE") is a shade darker so it's readable. (QW26, `700f41e`)

## Changes

- Screen readers announce the table's open/close buttons, sort direction and dialogs, and skip decorative symbols. Nothing visible changes. (QW26, `72ee261`)
- Code moves with no visible change: the `Subpages` folder name, and random IDs for added table rows. (O5, O6: `4bc24db`, `84f77d1`)
