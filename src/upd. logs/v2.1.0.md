# Website v2.1.0

**Unreleased.** On branch `fix/web` (quality-of-life round), not on `MASTER` yet. A medium update (+0.1.0).

## New

- **Press `/` to jump to the search box** on the Parts, Standard Parts, BOMs and Work Orders pages; Esc clears it. **The BOMs page has a search box** (name or catalog number). (QW1, `fea957e`)
- **Search Parts also finds parts by material, engineer, description and vendor,** ignoring case and extra spaces, and highlights the matching text. (QW2, `fea957e`)
- **Share a part by link:** Part Portal has a **Copy link** button, and opening that link (`…/#/partSearch?part=<id>`) opens the part's card directly. While a part is open on any page, the address includes it, so you can copy the address too. The extension's "Open on the website" uses the same link. (QW5, `0cec75e`)
- **Copy a catalog number with one click:** a small copy icon appears next to catalog numbers on hover (part cards, BOM / work-order / sub-assembly headers, Part Portal, the work-order list), with a short "Copied" note. Inside the BOM and work-order tables it comes later. (QW6, `0cec75e`)
- **A save indicator next to the BOM and work-order tables:** "Saving…" while edits are being sent, "Saved ✓" for a few seconds after, and "Not saved" in red when a save fails (the red error box stays too). (QW12, `909f9ee`)
- **A warning before leaving with unsaved edits:** closing or reloading the tab, or clicking a sidebar link, while an edit is still being saved or has failed asks first. (QW13, `306ebf6`)
- **Pulsing grey placeholders while lists and tables load,** instead of "Loading…" text. (QW20, `aa3fd89`)
- **Totals in the header card,** in the middle next to the description and engineer: on a BOM page "N parts · total quantity Q", on a work order "N parts · Q pieces · F finished (P%)". (QW11, `2251607`)
- **A BOM page lists its work orders** (name, owner, date; click to open), and **a work order has an "Open BOM" link** back to its assembly. It works with the current server too. (QW4, `d1eec77`)
- **Breadcrumbs on BOM pages** (Robot › Arm › Gripper) for the path you came through, and a **"Used in"** line listing every assembly that contains this one. Each shows the assembly's picture and opens it on a click. The path is kept in the address, so it survives a reload or a shared link. "Used in" appears once the new server is deployed. (QW3, `8a05f43`)
- **"Last published <date time> by <name>"** on the BOM page header. The name shows for saves made with the new server and extension; older records show just the time. Website edits are recorded as "website". (QW22, `a4c29b3`)
- **The work-order PDF always has a Size column and a "Done ☐" column** to tick by hand. (QW17, `0efe954`)
- **Export CSV** on the BOM page and the work order: the rows and columns the table shows, in the shown order, ready for Excel (Hebrew included). (QW9, `1093552`)
- **The Work Orders list shows each work order's progress** in the bottom middle of its card (a bar of finished / made parts and a count per status), and can be filtered by owner or "has unfinished parts" and sorted by newest, oldest or name. The progress needs the new server. (QW14, `81cde11`)
- **The image viewer zooms** (mouse wheel or pinch, up to 4×, drag to move around), **← / → show the previous / next picture** in the same table, and Esc closes it. (QW23, `f4eb0dc`)
- **Click the version in the top bar for "What's new":** every website version, built from these update logs (`src/upd. logs/`). (QW21, `abd98a9`)
- **Printing a BOM page prints just the table:** no sidebar, top bar, buttons or menus, full width in black on white, with the header row repeated on every page. (QW27, `874002c`)
- **Charts on the statistics page (/tele):** requests per day by kind, requests per user, and failures per day, in the current theme. They use the new server's totals and a chart library (Recharts, a new package, loaded only on that page). (QW28, `9c62dba`)
- **Tables remember their columns** in this browser: widths, order, sort and hidden columns, per page. Right-click a column header for **Columns…** (a checkbox per column) and **Reset columns**. The extension panel doesn't use this. (QW7, QW8, `767297b`)
- **The website works on phones and tablets:** nothing overflows sideways; header cards stack; list columns that don't fit move under the name instead of being cut off; toolbars wrap; frozen table columns take at most half a narrow table; dialogs nearly fill a phone screen and close with Esc or a tap outside; bigger tap targets. Checked at 320, 390, 820 and 1440 px wide in the browser's device mode. (QW25, `25fb61c`)
- **Messages appear as small notes in the bottom-right corner** (red for errors, grey for information) that close by themselves after a few seconds or on a click, instead of browser pop-ups you had to dismiss. (QW19, `b39f9c6`)
- **When you move around with the keyboard, the focused button or field gets a clear blue outline** (not when clicking with the mouse), and in light mode the faintest grey text (like "NO IMAGE") is a shade darker so it's readable. (QW26, `700f41e`)

## Changes

- A part size is always listed longest side first, even for an unusual bounding box (found by the new tests; sizes shown today don't change). (`e5e538e`)
- **BOM pages, work orders and work-order creation load an assembly in one request** from the new server's tree route, instead of one per level. With the current server they fall back to the old way. (`8c0a8dd`)
- Screen readers announce the table's open/close buttons, sort direction and dialogs, and skip decorative symbols. Nothing visible changes. (QW26, `72ee261`)
- Code moves with no visible change: the `Subpages` folder name, and random IDs for added table rows. (O5, O6: `4bc24db`, `84f77d1`)

## For developers

- **Unit tests:** `npm test` runs 23 tests (vitest, a new development package) for the tree loading, the table's rows, CNC groups and part sizes. (QX1, `29ee428`)
- **A checks workflow on every push and pull request** (`.github/workflows/checks.yml`): install, type check, lint, tests, the website build and both extension builds. Deploying is unchanged. (QX2, `026b770`)
