# Website v2.2.0

**Pushed:** 2026-11-23. A medium update (+0.1.0).

## Before you deploy

- **Redeploy the server (5.1.0) on Render**: `/health` and `/orphans` need its new routes. Until then they show a load error.

## New

- **Work orders: "Copy list"** button, under the CNC merge card on the left. It copies the parts currently shown (after filters, in table order) as plain text for messages to suppliers or WhatsApp: a header line with the work order's name and date, then one line per part, e.g. `5635-25-100 – Bracket ×4`. Invisible left-to-right marks keep each line in order when names are in Hebrew. A message says "Copied N parts". (`e0bf11e`)
- **Right-click "Open in Google Drive"** on any image, STL or Parasolid stored in Drive. In the BOM and work-order tables it's the last item of the row menu when you right-click that cell (greyed out when there's no file). Everywhere else (page titles, breadcrumbs, the BOM and work-order lists, part search, the part card, the image viewer) right-click shows a one-item menu. Images that aren't in Drive keep the browser's menu. (`0819abe`)
- **Two unlisted pages** (not in the menu; type the address):
  - **`#/health`, Data health:** every problem in the database from the server's check, one collapsible section per problem type, with count chips at the top that jump to their section, "Last checked", Refresh and a filter box. Each item links to its part card or BOM page, with the assemblies it's used in. Errors (red) are records a BOM points to that aren't saved; everything else is a warning (amber): problems that keep an item out of work orders. The "Not in any assembly" section says "Talk to Eyal for further questions." (`4b8372a`)
  - **`#/orphans`, Parts in no assembly:** each such part as a card with all its data, newest first, with a filter box. Each card has a **Delete…** button: the dialog asks for the admin secret (remembered for that browser tab), says how many of its files go to the Drive trash, and shows the result (deleted, or refused with the reason, e.g. "used by assembly Robot"). (`2e39be7`)
- `#/health` and `#/orphans` fit a phone screen.

## Not tested yet
