# Website v2.3.0

**Unreleased.** Committed on `MASTER` (`6c4c647`, `981f030`, `0f88dd2`), not pushed yet.

## Before it works

- **The server must be redeployed on Render** (server v2.3.0), or merging fails.
- Suggestions use part sizes, which come from Publish BOM in extension 2.2.0 or later. Parts published earlier can only be merged by hand.

## New

- **Merge work-order parts into CNC jobs.** Parts cut together in one CNC run (same thickness and material) can share one G-code link. (`0f88dd2`)
  - A **CNC merge** card under the filters suggests jobs, e.g. "Merge 3 parts: 6 mm · Aluminum 6061". Thickness is the smallest side of the part's saved size, rounded to 0.1 mm. Lathed, printed, externally produced and bought parts aren't suggested. The card also counts parts without a size.
  - To merge by hand: right-click a part, choose **Select for CNC merge**, then **Merge selected**. If one of the selected parts is already in a job, the others join it. **Remove from CNC job** takes a part out.
  - Merged parts sit next to each other and share one **Links** cell spanning their rows, like merged cells in Excel. Only the links are shared: each part keeps its own status, priority and progress. A part's own links come back when it leaves the job.
  - If the table is sorted or filtered so the parts are apart, each one still shows the job's links.
  - If someone else changed or removed the job meanwhile, you get an error and the jobs reload.
  - The PDF export doesn't show the jobs.
- **New work orders fill in the manufacturing method.** A part ticked STL in the extension gets "Printed", and one ticked Parasolid gets "CNC". Parts saved before the ticks existed go by the files they have. A part with both or neither stays "Manual". Existing work orders are unchanged. (`981f030`)

## Changes

- Tables can show merged cells (used by the Links column above). Tables that don't use it are unchanged. (`6c4c647`)

## Not tested yet

- Nothing has run in a browser or against the real server and database, in either theme. The grouping rules passed a scripted check: 6.04 mm groups with 6.0 mm, 6.2 mm stays separate, and lathed and unsized parts are left out.
- No work order was created to check the Printed / CNC defaults, since that writes to the database.
