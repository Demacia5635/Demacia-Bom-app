# Server v5.0.0

**Unreleased.** On branch `fix/serv`, not on `MASTER` yet. A large update (+1.0.0).

## Before you deploy

- **Set `ADMIN_SECRET` on Render** (any long random text, kept off the website and extension). It protects the Drive-sorting route.
- After the redeploy, run the sorting **dry run** first and read its report, then the real run (commands below, once the route is done).

## New

- **Drive files are sorted into assembly folders** (in progress). Inside each type folder (Images, STL, x_t) there's a folder per assembly, named by catalog number and nested like the BOM (e.g. `Images/2714-0000/2714-1000/2714-1100/`). A part used in several assemblies goes in the first one it's used in. Bought items go in a `Standard parts` folder, nested the same way for bought sub-assemblies. Files are only moved: their links don't change and nothing is deleted.

## Changes

- The Drive safety check accepts files in nested folders of the three team folders. (`e3062ae`)
- Internal Drive helpers for finding/creating folders and moving files, throttled and retried on Drive's rate limits. (`ae43b65`)
