# Server v0.1.0

**Pushed:** 2026-11-15 15:05 (commits `7eb4e40`–`4548f62`). The first batch of fixes from the code review: the low-priority items.

> **Known problem:** this version removed the server packages from the root `package.json`. Render installs only the root one, so the server crashed on its next start with `Cannot find package 'dotenv'`. Fixed in [v2.0.0](v2.0.0.md).

- `GET /api` answers with a health status instead of 404.
- Production types and statuses are looked up by their real ID.
- Drive file requests return proper error codes (404 for an unknown file, 502 for Drive problems) and the file's real type. Images keep their type; other files are sent as downloads.
- Internal error details are no longer sent to clients.
- Settings are read in one place (`server/config.ts`).
- Unused code was removed, and `npm run build` in `server/` now type-checks the server.
