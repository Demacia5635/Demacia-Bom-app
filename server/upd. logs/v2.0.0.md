# Server v2.0.0

**Pushed:** 2026-11-15, in parts between 15:40 and 20:13 (commits `e9ea512`–`0667cec`). The first official release.

## Before you deploy

- **Render must have `CLIENT_SECRET` set.** The server refuses to start without it.
- Redeploy on Render by hand, then check that `/api` answers `{"status":"online"}`.

## Changes

- **Starts on Render again.** The packages v0.1.0 removed from the root `package.json` (express, cors, dotenv, googleapis, mongodb, mongoose, morgan, node-fetch) are back. They must stay there for as long as Render installs from the repository root.
- **Refuses to start without `CLIENT_SECRET`.** Before, a missing secret left the whole API open.
- **Drive access is limited to the team's three folders** (images, STL, Parasolid). A check of all 63 stored file references on 2026-11-15 found them all inside those folders, so existing records are not affected. Reading a file still needs no secret (images are shown with `<img>` tags); that waits for the authentication decision.
- **Saving a whole work order no longer resets other people's per-part progress.** The part list is written only when the work order is created. Parts added to a work order later start at 0 made, not 1.
- Saves accept only plain field values: database commands, dotted paths and server-owned fields (IDs, timestamps) are ignored. Two people creating the same record at once no longer causes an error.
- Drive file types are read correctly (they were always reported as unknown).
- An unused Drive upload lock was removed.
