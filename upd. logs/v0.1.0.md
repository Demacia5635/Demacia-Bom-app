# v0.1.0

**Deployed:** 2026-11-15 (commits `7eb4e40`–`4548f62`, pushed to `MASTER`)

The first batch of fixes from the code review: the low-priority items.

## Extension

- The Demacia button in Onshape no longer stays hidden after a temporary error. It retries after 2, 5 and 15 seconds.
- The button is placed less often, so it uses less CPU on busy Onshape pages.
- Refresh BOM is disabled while the parts of a sub-assembly are still loading, so rows can no longer appear twice.
- An empty sub-assembly is treated as an assembly, not as a part, so it no longer causes failed STL/Parasolid exports.
- Saved Onshape links use the Onshape address the tab is actually on, which fixes links for enterprise accounts.
- Edits are saved to the local copy once you pause, not on every keystroke. When storage is full, the oldest saved assemblies are removed first.
- The image cache is trimmed: images older than 60 days are removed, and at most 3000 are kept.
- Telemetry counts requests correctly when two operations overlap.

## Website

- Links open in a new tab safely (`noopener`), and only `http(s)` links are opened.
- Tables pick up column changes, React warnings in dropdown cells are gone, and arrow keys only move within the same table.
- A work order built from a BOM that contains itself shows an error instead of loading forever.
- The theme toggle now applies to the BOM pages too, and a missing-stylesheet error on every page load is gone.

## Server

- `GET /api` answers with a health status instead of 404.
- Production types and statuses are looked up by their real ID.
- Drive file requests return proper error codes (404 for an unknown file, 502 for Drive problems) and the file's real type. Images keep their type; other files are sent as downloads.
- Internal error details are no longer sent to clients.
- Settings are read in one place (`server/config.ts`).
- Unused code and packages were removed, and `npm run build` in `server/` now type-checks the server.
